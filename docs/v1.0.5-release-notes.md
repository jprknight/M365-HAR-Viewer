### Highlights

- Added an Apache License 2.0 license and explicit contribution licensing.
- Added a public security-assurance matrix, data-handling inventory, security
  testing guide, and support-engineer operating guide.
- Expanded the threat model with trust boundaries, a data-flow diagram, a risk
  register, residual risks, and review triggers.
- Strengthened private vulnerability reporting, response targets, incident
  handling, and release-withdrawal guidance.
- Added repository ownership, pull-request security checks, and safe public
  issue templates.
- Enabled private vulnerability reporting, Dependabot security updates, and
  default-branch rules requiring pull requests, successful CI and security
  checks, resolved review threads, linear history, and protection against
  deletion and force pushes.
- Added a hash-verified Microsoft SBOM Tool step that generates and validates
  an SPDX 2.2 SBOM from the final Windows publish output.
- Release downloads now include the versioned SPDX SBOM, ZIP and SBOM
  checksums, build provenance, and an SBOM attestation.

This release does not change trace-processing behavior or the loopback-only
runtime boundary introduced in version 1.0.4.
