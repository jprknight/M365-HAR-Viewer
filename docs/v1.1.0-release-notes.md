### Highlights

- Added a collapsible trace summary with drill-through for severity, HTTP status, findings, failing hosts, slow sessions, and authentication classifications.
- Added composable structured filters and debounced search across URLs, headers, bodies, classifications, findings, evidence, and recommendations.
- Expanded HAR and SAZ metadata fidelity and added explicit import-quality reporting for partial, skipped, truncated, unsupported, invalid, and missing-response content.
- Added cancellable import, analysis, and summary operations with stale-result protection when a newer trace is opened.
- Virtualized the session grid while preserving sorting, filtering, selection, accessibility, and keyboard navigation across off-screen rows.
- Added repeatable 1,000, 10,000, and 100,000-session performance budgets. The 100,000-session validation reduced peak managed memory from approximately 1.2-1.5 GiB to 595-812 MiB.
- Expanded packaged Chromium coverage to HAR, unencrypted SAZ, and AES-256 encrypted SAZ files, including incorrect-password recovery and decrypted response inspection.
