### Highlights

- Enforced a loopback-only local web server on IPv4 and IPv6 so the analyzer
  cannot be exposed through a wildcard or network-interface binding.
- Replaced the flexible `--urls` option with a constrained `--port` option that
  changes only the local listening port.
- Rejects attempts to use `--urls` with a clear error instead of accepting a
  potentially network-accessible configuration.
- Prevents `ASPNETCORE_URLS` and other URL configuration sources from
  broadening the listener beyond the local computer.
- Restricted accepted Host values to the local loopback hosts.
- Added regression coverage for port parsing, removed URL configuration,
  loopback listener behavior, and Host validation.
- Added a public security policy with private vulnerability-reporting guidance.
- Added public security, privacy, and threat-model documentation covering data
  processing, temporary storage, network communication, trust boundaries,
  mitigations, residual risks, and review triggers.
- Added secure contribution requirements that prohibit customer diagnostic data
  and require synthetic or appropriately sanitized fixtures.
